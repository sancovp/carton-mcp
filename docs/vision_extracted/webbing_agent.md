# webbing_agent

## THE WEBBER IS THE ENCAPSULATION ENGINE
The webber sees that a final contextual thing closing a fiat boundary was added, REIFIES that fiat
boundary as a concept, and that concept becomes the highest-level thing pulled during rehydration.

## A FIAT BOUNDARY CLOSES WHEN THE LAST THING THAT COMPLETES IT ARRIVES
A fiat boundary is one we DRAW rather than one reality supplies: a sprint, a thread, an arc, a phase.
Nothing physical closes them, so their closure is a fact about the GRAPH.

## DETECTION IS PROGRAMMATIC, NEVER A JUDGMENT
Closure is COMPUTED from the inheritance graph: when everything that must be `part_of` X exists and is itself closed, X is closed. The webber does not decide that a sprint ended.

## The loop
Work is webbed AS IT HAPPENS. On the write that completes a fiat boundary, it recognizes the closure and reifies the containment. The containment is the highest-level abstraction for that set, and that is what rehydration pulls.

## THE HYGIENE HALF IS THE INPUT TO THE ENCAPSULATION HALF
Referent-completeness — every referent an entry names is a real node, every path it cites resolves — is
what makes closure computable over the inheritance graph.
They are one mechanism, not two concerns.

## A BOOKKEEPING FLAG TAKES THE SCRATCH LANE
Marking a concept examined-and-sufficient records the webber's own pass over it and claims nothing about
the ontology, so it takes the direct property write and emits no per-concept validator trail.
A tick that marks many concepts writes them as ONE batch, never as one event each.

## A COUNT THE LANE REPORTS IS MEASURED ON THE CALL THAT REPORTS IT
A pending count that fails to compute is reported as UNKNOWN pending, never as a lane failure. The model the webber is invoked with is the model the webber's own spec names. The record a tick writes REPLACES the record of the tick before it, or each key carries the time it was taken. A healthy pair from an early tick never stands beside an error from a later one.

## THE LANE CALLS ITS FUNCTION AND DOES NOT LAUNCH A PROCESS TO REACH IT
A worker reaching a function in its own package calls it directly, with no subprocess and no timeout on
that path.
A DRAIN REPORTS WHETHER IT CONVERGES, never only its depth: a lane completing fewer items than arrive
reports LOSING.

## THE WEBBER ONLY ADDS
The webbing agent writes only new nodes and new triples and never edits one. A wrong node gains
`is_a WrongThing` and a `wrong_because` edge pointing at its evidence.
Its edge vocabulary is fixed and typed: `about`, `relates_to`, `wrong_because`, `cause_category`,
`supersedes`, `depends_on`, `evidence_for`.

## THE WEBBER FINDS TWO KINDS OF REFERENT
THINGS are named nouns, named as `this_qua_that`. HAPPENINGS are a relation among several named things occurring in the text with NO node — a hyperedge that is not reified. A happening is REIFIED as a concept whose node is an object referring to that morphism. The webber loops over a description until it names nothing unreified.

## THE WEBBING REACHES THE TASK QUEUE
Cards and the types they carry are webbed until what the agent is doing is clear.

## WEBBING A CONCEPT AUTHORS ITS RETRIEVAL STATE MACHINE
When the webber webs a concept it authors a retrieval state machine for understanding that concept.

## THE EMBEDDING TEXT IS VARIED PROSE
The coherer generates varied natural-language prose from a concept's relationships for the chroma
embedding, never a deterministic template.

## THE WEBBER SAYS WHAT A THING IS AND NEVER INVENTS A PARENT OR A CHILD
INVENTING CHILD CONCEPTS OR PARENT CONCEPTS IS RELATIVE. It says what the thing IS, in the form THIS_QUA_THAT, and a `this_qua_that` changes over time. A name carrying two senses resolves as two qua-named things rather than one colliding stub. A STUB WHOSE CONTENT ALREADY STANDS SOMEWHERE IS FILLED FROM THAT PLACE, NEVER DESCRIBED AFRESH. An auto-created node that an entry names while carrying its full statement is promoted by webbing that statement onto it.
