# manifold

## ONE HIERARCHY
Every concept is attached to a domain that climbs `part_of` through subdomain, domain and HWSS stratum to one literal root, Carton_Manifold, whose top-level parts are Health, Wealth, Social and Spiritual.

## EVERY TYPE'S FIELDS RELATE TO THE CHAIN THAT ASSEMBLES THE OTHERS
Every type's fields relate to the chain that assembles every other type's fields.
`Doc_Mirror_Journal_Entry` carries a required restriction that it is part_of a Conversation: SOMA grades an
unjoined entry soup with the gap named, and the journal CLI fills that gap on write.

## TERRAFORMING WALKS A DOMAIN UP THE GRADIENT
Terraforming a domain walks it up the SOMA gradient until all four lenses (agent, place, code, domain)
render.

## EVERY DOMAIN REACHES CARTON_MANIFOLD
The write path places a domain in the hierarchy when it is minted: a domain arriving as a relationship target gets a part_of edge toward Carton_Manifold at write time. A rooting backfill gives every bare-top domain a part_of edge that reaches Carton_Manifold, resolving near-synonym domains rather than cementing them.
