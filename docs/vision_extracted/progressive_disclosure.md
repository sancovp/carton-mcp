# progressive_disclosure

## THE CONTAINMENT TOWER IS THE PROGRESSIVE DISCLOSURE GEOMETRY
The containment tower, the vision dependency edges and the disclosure DAG are ONE geometry, not three
features.
That geometry is what FLOWS are eventually made with, using carton's more advanced features.

## THE ENTRY POINT IS A DAG NAVIGATED DOWN TO A LEAF THAT IS A TOOL USE
The disclosure entry point is a DAG of concepts. Navigating down it ends at a LEAF THAT IS A TOOL USE.

## A SECOND GRAPH CARRIES FEEDBACK BACK
A second graph carries feedback from leaf outputs back to the frontend.

## THE WHOLE SYSTEM DISCLOSES THROUGH ITS CLIS AND REHYDRATION SURFACES
Progressive disclosure of the whole system is carried by the CLI and rehydration surfaces.

## THE DISCLOSURE DESCRIPTION LIVES ON THE UNIVERSAL, NEVER IN A HAND-WRITTEN RENDERER
Every thing carries, on its declared universal, the description of how to disclose it. A thing with no declared universal has nowhere for its disclosure description to live, and a hand-written renderer cannot know what may be pulled next. Only the universal knows. A RENDER ANSWERS THE QUESTION ASKED AND THEN OFFERS THE NEXT LAYER. It returns the value asked for plus the link to more, and what comes next is an INDEX OF OPTIONS rather than the material itself. The layer after that discloses the same way, without bound.
