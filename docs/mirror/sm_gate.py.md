## Purpose (one paragraph)
`sm_gate.py` is a **scientifically-exact port of CyberneticiRcus's (CCC's) gated state machine** (`cyberneticircus/lib/gates.py` + `lib/state_machines.py` + `neo4j_cypher_mcp/server.py`) onto carton's own `:Wiki` graph (`:1-46`). Isaac's mandate (`:6-9`, verbatim): "IT IS A STATE MACHINE YOU CAN PROGRAM IN CARTON THROUGH ADD CONCEPT AND SET PROPERTIES ... EVERY SINGLE OTHER APPLICABLE THING THAT CALLS CYPHER OR RETRIEVES ANY INFORMATION FROM ANYWHERE ARE GATED BY THE STATE MACHINE AND ACTIVATE/CHECK IF THEY ARE LEGAL." The SM is graph DATA: `State_Machine -[:HAS_STEP]-> Traversal_Step -[:NEXT_STEP{weight, required_pattern, warrant}]-> Traversal_Step`, `-[:CALLS_SM]->`; each step carries a `required_pattern` regex + `text`. A per-ACTOR cursor `(actor)-[:HAS_LIFECYCLE]->(Execution_State{status})-[:CURRENT_STEP]->(Traversal_Step)`. **THE GATE:** while an actor is LOCKED at a step, every call's canonical text MUST match the step's `required_pattern`; a match passes AND auto-advances (a branch chosen by `select_branch`, or UNLOCK at a terminal step); a non-match is REFUSED with a `GateRefusal(PermissionError)` whose message IS the next-move instruction. **SAFETY:** DEFAULT-UNGATED, a file KILL SWITCH, and every gate path FAILS OPEN. PURE w.r.t. the live MCP: every graph-touching function takes an injected `run(query, params) -> rows`; the `*_live` entries open their own connection for callers in OTHER processes. Beyond the core gate: the Agent_Identity ENTITY resolution layer; the per-concept **Sm_Chain** require-next stack; the skill→SM converter and the generic factory `create_sm_chain`; **BRANCHING** (`select_branch`, softmax over weight) with **weight reinforcement** that now records a verbatim **WARRANT** on the edge; the P0 **episode ledger**; and the graph→system-prompt generator. **CHANGED since the 2026-07-06 doc(m):** (1) the type-shattering fix d05c8a56d (2026-08-22) — every relationship `MERGE` whose target was an anonymous inline `(:Wiki {n:'<Type>'})` now BINDS the type node first (`MERGE (t:Wiki {n:'X'})` then `MERGE (a)-[:IS_A]->(t)`), at six sites in this file; (2) the Edge_Warrant_Field dc0a9d5b4 (2026-08-09) — `reinforce_transition` takes a `warrant` and `auto_progress` composes it from the real decision; (3) the branching header comment corrected d93b3776c (2026-07-12).
